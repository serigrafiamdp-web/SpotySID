# TEST449 — First browser D81 export (experimental)

SpotySID embeds the exact approved SIDPLAY64MIX TEST92 PRG from commit 01b6ae49a1dd75c0abaa33ba1e6804905509282a (Git blob 39930e8cc09a4a19a98010303fac2d650abfdd34; SHA-256 b718b6a3efdb59d8993f5132cbbcb4c84a1aa2f110ab1591553f391198dfd1db). The original player repository is not modified.

Choose a playlist, click CREATE C64 DISK, choose D81. The preflight reads each original SID and checks its header and SHA-256 against the exact 100-track TEST92 corpus. Unmatched files are skipped; this is deliberately conservative and does not certify arbitrary NordischSound tracks. The current lookup has room for 100 tunes and nine high-address entries. Duplicate entries are counted against these limits. Candidate order is preserved; exported PRG filenames begin with a unique three-digit sequence followed by an abbreviated title and .sid. The player is first, named 00player.prg. Original SID payloads and headers are not modified.

The fresh D81 writer is an isolated small JavaScript proof of concept, not a vendored copy of the external CBM Disk Editor. It generates 819,200-byte images with a 1581 header, BAM, directory and file chains; the same module independently reads the generated image, checks entry order, filenames, file types, payloads, sector bounds, chain overlap, block counts and BAM. A 60-block player plus up to 3,100 data blocks are allocated outside track 40. The per-disk copy of TEST92 patches only the verified 100-entry fade low-address lookup and nine high-address index slots; unused special indices are FF. No new player boot or music code.

Validation before deployment: 11 structural cases (directory boundaries through 100 entries and full data capacity), overflow rejection, exact original-order player identity and reversed-order remap. No actual VICE playback or c1541 validation yet. The full 100-track reference manifest was extracted from the approved TEST92 D81; exact hash matching is required. D64 remains preflight only. Song-length metadata is displayed but not injected: native automatic Krill handoff still needs timer support before individual durations can be guaranteed. No generic fade support or arbitrary playlist compatibility claimed. This is a controlled TEST, not a finished exporter.
